# TT Family's Household - Infrastructure Blueprint

## 🎯 Vision
A high-performance SRE monitoring ecosystem. Decoupled, real-time, and architected for industrial-grade stability, process-level analysis, and intelligent predictive insights.

## 🛠️ Tech Stack
- **Agent**: Node.js (Arch Linux) - Modular collectors with **Linux Ops Telemetry** (Process monitoring).
- **Database**: Supabase (PostgreSQL) - Real-time CDC with **SRE Core Migration** (JSONB process logs & caching).
- **Frontend**: Next.js 15 (Vercel) - **Tremor Charts** & **HeadlessUI Modals** for deep-dive diagnostics.
- **Intelligence**: **Native REST AI Resilience** - Using Gemini v1 Stable with a deterministic SRE Fallback Rule Engine.

## 📜 Best Practices
1.  **Dependency Lean**: Minimal use of heavy SDKs. Native `fetch` for AI resilience and stable REST endpoints.
2.  **Process-Level Visibility**: Monitoring is not just metrics; it's identifying the root cause (Top Processes).
3.  **Intelligent Caching**: 15-minute AI TTL to optimize API quotas and ensure sub-second dashboard performance.
4.  **UX Stability**: Always use **Hydration Guards** and fixed-height Tremor containers to prevent layout shifts.

## 🏗️ Core Features
- **Daily Standup**: Sarcastic technical summaries of household activity generated by Texas (SRE Advisor).
- **Process Monitor**: Deep-dive modals showing real-time CPU/RAM consumption per process.
- **SRE Fallback**: Deterministic system reports provided even when external AI services are unreachable.
- **Unified Pulse**: Combined AreaCharts for instant multi-metric correlation.

## 🏗️ Architecture Flow
`Agent (Linux Ops)` -> `Supabase (SRE Core)` -> `Dashboard (Tremor UI)` -> `AI Resilience Layer`
